Lista de Exercícios — DSR (Aulas 01 a 06) Questão 01 Em arquiteturas de software distribuídas, uma das principais diferenças conceituais entre sistemas monolíticos e soluções remotas é a forma como os componentes interagem. Qual é uma premissa técnica indispensável ao projetar comunicações entre nós remotos? a) A rede corporativa deve ser tratada como um canal 100% confiável e de latência zero. b) Todas as chamadas entre nós devem ser síncronas para garantir atomicidade imediata sem o uso de transações distribuídas. c) Falhas parciais de infraestrutura, oscilações de banda e partições de rede devem ser tratadas como regras esperadas de projeto, e não como exceções raras. d) A escalabilidade horizontal dispensa a preocupação com o consumo de CPU na serialização de mensagens. Questão 02 No protocolo HTTP, o código de status retornado pelo servidor deve refletir com precisão semântica o resultado da operação. Quando uma requisição POST resulta na criação bem-sucedida de uma nova entidade no banco de dados remoto, a resposta recomendada pelas boas práticas RESTful é: a) 201 Created, contendo idealmente o cabeçalho Location apontando para a URI do novo recurso. b) 200 OK, com o ID numérico concatenado diretamente na URL de requisição. c) 204 No Content, garantindo que nenhum byte adicional trafegue de volta ao cliente. d) 304 Not Modified, instruindo o cliente a buscar os dados no cache local. Questão 04 Considere um sistema de agendamento em que o cliente HTTP envia a mesma requisição repetidas vezes devido a instabilidades de rede móvel (quedas de sinal momentâneas). Questão 08 O formato JSON é amplamente adotado em APIs REST.
