Programação Web I

Fundamentos para compreender a web e criar páginas acessíveis, responsivas e interativas usando HTML, CSS e JavaScript.

12 aulas Front-end HTML5, CSS e JavaScript
Plano de aulas

Do navegador à primeira página publicada

Abra o resumo de cada aula para consultar os conceitos e o resultado esperado do encontro.

Aula 01

Como a internet funciona

Cliente, servidor, endereços IP, DNS, URLs e o caminho de uma página até o navegador.

Ver resumo da aula

A turma reconhece como uma requisição sai do navegador, encontra um servidor por DNS e recebe uma resposta. Também diferencia internet, web e endereço URL.

Acessar aula
Aula 02

HTTP, HTTPS e navegadores

Requisições, respostas, métodos HTTP, códigos de status e navegação segura.

Ver resumo da aula

A aula apresenta a conversa entre cliente e servidor com HTTP. O estudante interpreta URL, cabeçalhos, status como 200 e 404, e entende a proteção oferecida pelo HTTPS.

Acessar aula
Aula 03

Ambiente e ferramentas

Editor de código, extensões, DevTools, estrutura de projeto e boas práticas de arquivos.

Ver resumo da aula

Configuração do VS Code e uso das ferramentas do navegador para inspecionar elementos, editar estilos e identificar erros. A turma cria sua pasta de projeto web.

Acessar aula
Aula 04

Estrutura do HTML5

DOCTYPE, html, head, body, metadados e a primeira página semântica.

Ver resumo da aula

O estudante monta um documento HTML5 válido e entende a função de cada área. São introduzidas tags de texto, títulos, parágrafos e comentários no código.

Acessar aula
Aula 05

HTML semântico e conteúdo

Hierarquia de títulos, listas, links, imagens e regiões semânticas da página.

Ver resumo da aula

A aula organiza conteúdo com header, nav, main, section, article e footer. O foco é criar páginas legíveis para pessoas, buscadores e tecnologias assistivas.

Acessar aula
Aula 06

Formulários e tabelas

Campos, labels, validação nativa, botões, tabelas e dados estruturados.

Ver resumo da aula

São construídos formulários com associação correta entre label e input, tipos adequados de campo e atributos de validação. Tabelas são usadas somente para dados tabulares.

Acessar aula
Aula 07

Introdução ao CSS

Seletores, cascata, herança, cores, tipografia e arquivos de estilo externos.

Ver resumo da aula

O estudante conecta CSS ao HTML e aplica estilos com seletores claros. A aula explica cascata e especificidade para evitar conflitos e repetição desnecessária.

Acessar aula
Aula 08

Layout com CSS

Box model, display, Flexbox, Grid, espaçamentos e composição de interfaces.

Ver resumo da aula

A turma organiza blocos e componentes usando o modelo de caixa, Flexbox e CSS Grid. O resultado é uma página com layout previsível e bem espaçado.

Acessar aula
Aula 09

Design responsivo

Mobile first, media queries, unidades relativas e imagens que se adaptam à tela.

Ver resumo da aula

O estudante ajusta sua página para celulares e telas maiores sem duplicar conteúdo. São aplicados media queries, medidas flexíveis e testes no modo responsivo do navegador.

Acessar aula
Aula 10

JavaScript: lógica e DOM

Variáveis, condições, funções, eventos e seleção de elementos da página.

Ver resumo da aula

A aula introduz a linguagem JavaScript e mostra como reagir a cliques e alterar o DOM. A prática cria uma interação simples mantendo HTML, CSS e JS separados.

Acessar aula
Aula 11

Acessibilidade e qualidade

Semântica, contraste, teclado, textos alternativos e validação do código.

Ver resumo da aula

A turma revisa a página sob a perspectiva de diferentes usuários. O encontro trata de navegação por teclado, contraste, alt em imagens e validação de HTML e CSS.

Acessar aula
Aula 12

Projeto e publicação

Integração dos conteúdos, revisão final e publicação de um site estático.

Ver resumo da aula

A turma entrega uma página ou pequeno site autoral. O projeto consolida estrutura, estilo, responsividade e interação, com revisão do código antes da publicação.

Acessar aula
